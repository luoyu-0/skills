# Agent Skills

本项目收集可复用的 Agent 技能。每个技能放在 `skills/` 下的独立目录中，以 `SKILL.md` 描述适用场景和工作流程，供支持该格式的不同 Agent 使用。

## 现有技能

| 技能 | 简介 |
| --- | --- |
| [git-delivery](./skills/git-delivery/SKILL.md) | 评估并提交 Git 仓库修改、创建 PR，以及结合本地运行效果审核远程 PR。 |

## 如何使用

1. 在 `skills/` 中选择所需技能，阅读其 `SKILL.md`，确认适用场景和操作边界。
2. 按所用 Agent 的要求加载技能目录或 `SKILL.md`。若 Agent 不支持自动发现技能文件，可以将内容作为任务指令提供给它。
3. 确保 Agent 具备任务所需的本地工具和权限。用户的明确要求及目标项目的规范优先于通用技能说明。

不同 Agent 的安装位置和加载方式并不相同，本仓库不依赖某个产品专用的配置路径。让 Agent 参与维护本仓库时，请同时提供 [AGENT.md](./AGENT.md)。

## 如何参与贡献

1. 新增技能时，在 `skills/<技能名>/` 下创建 `SKILL.md`；修改现有技能时，保持目录名和内容一致。
2. 在 `SKILL.md` 开头提供 `name` 和 `description`，说明技能何时适用；正文写出可执行的步骤、完成条件和必要的边界。
3. 使用简体中文编写说明，代码和技术专有名词可保留英文。避免绑定单一 Agent 的专用命令；确需依赖特定工具时，说明可替代的通用操作。
4. 更新本页的技能列表，检查链接和 Markdown 格式，并记录实际完成的验证。提交变更前遵循 [AGENT.md](./AGENT.md) 中的仓库规范。

欢迎通过 Issue 说明需求或通过 PR 提交改进。请让一个变更聚焦一个明确目的，并在 PR 中说明背景、主要改动、验证结果和影响。
