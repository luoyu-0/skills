# Agent Skills

本仓库收集可复用的 Agent 工作技能。技能以独立目录组织，核心说明写在 `SKILL.md` 中，目标是供支持技能文件的主流 Agent 使用，不绑定某个特定产品。

## 现有技能

| 技能 | 用途 |
| --- | --- |
| [git-delivery](./git-delivery/SKILL.md) | 完成 Git 仓库修改后评估并提交本轮成果；在用户明确要求时，调查变更与验证证据并创建 PR。 |

## 使用方式

1. 阅读目标技能目录中的 `SKILL.md`，确认其适用场景与行为边界。
2. 将整个技能目录放到所用 Agent 支持的技能位置，或按该 Agent 的配置方式加载 `SKILL.md`。不同工具的目录与加载方式可能不同，请以各自的说明为准。
3. 在任务中按需启用技能。用户的明确要求、目标项目的协作规范和现有模板优先于技能中的通用流程。

技能描述的是工作流程，并不替代 Agent 所需的文件系统、Git 或代码托管平台权限。若所用 Agent 不支持自动发现 `SKILL.md`，也可以将相关内容作为任务指令提供给它。

## 仓库结构

```text
.
├── README.md
└── git-delivery/
    └── SKILL.md
```

每个技能使用独立目录，`SKILL.md` 包含名称、适用场景和操作规则。后续技能可按相同结构添加。
